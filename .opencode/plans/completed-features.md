# Completed feature outcomes

This file records the disposition of the candidate features from the former
backlog.

## Implemented

- Achievements derived from game statistics and shown in the Hangar.
- Dock-required module sale and refining actions.
- A dismissible first-time tutorial hint for DEMO mode.
- A post-certification storyline mission in Placid.
- Rotating daily agent contracts for combat, hauling, and mining.
- Per-system security levels that affect combat, market prices, and ambush risk.
- An offline-resume report using the existing capped offline simulation.
- Tier IV modules and ship blueprints with crafting support.
- Persistent fitting presets with cost/refund adjustment when applying them.

## Deliberately deferred

- Multiplayer and instancing remain out of scope for this single-player game,
  consistent with the product requirements.
- Committing the accumulated work was left undone; no commit was requested.
